# Security Policy

## Reporting A Vulnerability

Please report security issues privately through GitHub's security advisory flow if enabled for the repository, or by opening a minimal issue that does not include exploit details.

Do not include private images, API keys, model files, system paths, or credentials in public reports.

## Supported Versions

The `main` branch is the currently supported development version until tagged releases begin.

## Data Safety

This package does not require API keys and does not intentionally collect, transmit, or store user data. Example workflows may load images from your local ComfyUI input folder; choose test images carefully and do not share private outputs in issue reports.
