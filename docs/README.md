# Krea Reference documentation

![V11 synthetic reference-guided example](assets/krea-v11/reference-style.png)

Start with V11. Package 0.5.0 introduces the V11 node classes; earlier workflows continue to use their original classes.

For native image editing, current GitHub source also includes experimental
V12 preparation nodes and V13 carrier sliders. Start with the [V13 setup and
actual illumination comparison](krea-v13-native-carriers.md#setup-and-first-comparison).
These require the documented native host revisions and have a narrower
validation scope than the V11 starting workflows.
