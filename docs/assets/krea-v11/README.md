# V11 example images

Synthetic examples generated for this project and published with the maintainer's permission. No user/client photographs are included. Pixels are unchanged; embedded local workflow/path metadata has been removed. Download the separate native JSON workflows to open a canvas; these documentation PNGs do not embed a workflow.

Reference anchor/style outputs: seed 424242, INT8 ConvRot, Qwen3-VL FP8 scaled, Qwen image VAE,512 square,8 Euler/simple steps,CFG 1,shift 3.14. Slider neutral/tiny/+3 comparison uses the same seed/settings. Neutral is a plain-prompt control; zero-reach/budget/cancellation V11 renders matched that control exactly. The reference anchor panel uses the unchanged balanced recipe; it is not the two-card identity setup. See the gallery captions for that distinction.

Slider showcase: native V11 showcase graph, NVFP4,1024x1536,seed 424242,8 Euler/simple steps,CFG 1. It uses the saved multiple-card setup, not a single brightness axis.

Reference inputs were freshly generated synthetic teapot and botanical artwork. Seeds 81000 and 81001 respectively. The results illustrate behavior, not a universal quality or identity guarantee.

[Exact comparison settings](settings.json) record prompts, card controls and sampler values without local file paths.
